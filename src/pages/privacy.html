Privacy

Browse without an account

This portal provides public information, not a personal-data submission service.

Information you provide

The site has no account registration, application forms, payments, or personal submissions. Do not send identification documents, private contact details, or sensitive personal information through external project channels.

Browsing and third parties

The static hosting provider may process routine request information such as IP addresses, browser details, and request times under its own policies. This site loads fonts from Google Fonts. External map resources, when loaded, may also receive network request information. We cannot promise that third-party infrastructure keeps no logs.

Links to official sources and other websites leave this portal. Those services have their own privacy practices. Search and filter controls are for exploring portal records, not submitting reports to government.

Project map backgrounds

The Project Locations map uses OpenStreetMap tiles by default. Your browser sends the tile provider your IP address, normal browser request information, the referring site, and requests identifying the map areas and zoom levels you view. OpenStreetMap has its own privacy policy and tile usage policy; availability is not guaranteed.

Select No basemap / local reference to stop further background-tile requests while keeping project coordinates and available boundaries. Already requested tiles cannot be recalled. Ordinary browser caching is respected; this portal does not bulk-download tiles, prefetch offline regions, proxy tile traffic or send project searches to a routing service. Coordinate links to OpenStreetMap open only when selected. Exceptional global-coordinate inspection uses no remote tiles.

Public records

Public availability is not a reason to republish unnecessary personal details. Contributions should use only information needed to explain a public record and avoid sensitive identifiers. A dedicated privacy contact channel has not been published; this page does not invite personal-data submissions.

Read the methodology and corrections policy for publication limits.
