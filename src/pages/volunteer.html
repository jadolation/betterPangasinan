Get Involved

Join the Movement

Better Pangasinan is an independent volunteer-led project. Developers, designers, researchers, writers, and residents can help make public information clearer and more accessible.

Read our methodology Review corrections guidance
Where You Fit In

No matter your background, there's a role

Developers

Help build and maintain the site, data pipelines, and open-source tools on GitHub.

Designers & Writers

Shape how provincial and local data reads and looks, from accessible layouts to source-based explanations.

Researchers & Residents

Gather and verify public records, ordinances, and budget documents from official sources.

How to Start

Getting involved

Start with the methodology and the repository's README if you have access to the project source. A dedicated public volunteer contact channel has not been published. This site does not accept applications or personal submissions.

Improve the tools

Work from the source files, run the build and tests, and keep changes accessible. Do not publish test fixtures as public records.

Review the evidence

Check official source documents, reporting periods, units, and responsible offices. Avoid private personal details and unsupported allegations.
